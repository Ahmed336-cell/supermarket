# Supermarket desktop

macOS client for the supermarket API.

## Run

1. Start the API in `supermarket-api` (port 4000).
2. From this folder:

```bash
flutter run -d macos
```

Seeded admin: `admin@shop.local` / `Admin123!`

API base defaults to `http://127.0.0.1:4000`. Override with `--dart-define=API_BASE=http://host:port`.
